# Third-party notices

Generated by `scripts/supply_chain.py render` from the committed inventories. Do not edit by hand. ## Dataset citations

Every dataset whose terms carry over to a shipped model, with the citation the source asks for (from [`docs/DATASETS.md`](../DATASETS.md)):

- **PPG-DaLiA** (CC BY 4.0 (stated on the page)). Cite: A. Reiss, I. Indlekofer, P. Schmidt, K. (2019), PPG-DaLiA [Dataset], UCI Machine Learning Repository, doi:10.24432/C53890

Reyes-Ortiz, "A Public Domain Dataset for Human Activity Recognition using Smartphones", ESANN 2013
